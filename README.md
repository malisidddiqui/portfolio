It’s built entirely with **HTML, CSS, and JavaScript**, focusing on clean code and a responsive layout.

- **Project Showcase:** Highlights my best work with descriptions and live links.  
- **Contact Section:** Easy ways to connect with me via email or social media.  
- **Smooth Navigation:** Clear structure and consistent theme across pages.
